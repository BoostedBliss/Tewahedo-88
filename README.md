# 🕊️ Ethiopian Bible 88 Canon & Reader 📖✨

Welcome to the **Ethiopian Bible 88 Canon & Reader**! 🇪🇹✨ This is a beautifully designed, interactive Bible reader featuring the complete and historical 88-book Ethiopian Orthodox Tewahedo Church canon. 🌿

## 🌟 Features

- **📜 Complete 88-Book Canon:** Explore the full Ethiopian Biblical canon!
- **📊 Cross-Canon Comparison Dashboard:** Easily compare the Ethiopian 88-book canon with the KJV (80 books) and Protestant (66 books) canons. 🔍
- **🎧 Audio Narration:** Listen to verses with soothing audio narration. 🎵
- **🖍️ Verse Highlighting:** Highlight your favorite passages and save them! 🎨
- **🔌 Offline Access:** Read anywhere, anytime, without needing an internet connection. 🌍

## 🛠️ Tech Stack 💻

We built this app using some incredibly awesome and modern technologies! 🚀

- **⚛️ React** - The amazing UI library.

## 🚀 Getting Started

Ready to dive in? Here’s how you can get this project running on your local machine! 🌈

### 📋 Prerequisites

Make sure you have Node.js and npm (or bun/yarn) installed on your computer. 🖥️

### 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd <your-project-directory>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or bun install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser!** 🌐
   Navigate to `http://localhost:3000` (or the port Vite provides) and start exploring! 🎉
